# File Tree

Current intended source tree:

```text
minspec/skeleton/
├── .editorconfig
├── .gitattributes
├── .gitignore
├── AGENTS.md
├── LICENSE
├── README.md
├── TREE.md
└── composer.json
```

This is intentionally not a full generated Symfony application tree.

After `composer create-project minspec/skeleton my-app`, Composer and Symfony Flex are expected to generate the application files in the created project.
